# kowake-seyo

案や論点が多いときに、全体の方針を先に示し、一件ずつ議論して決めるスキルです。

このファイルは人が読むための説明です。エージェントが読むのは `SKILL.md` です。

## 使い方

名前を出して頼みます。

```
kowake-seyo で、さっきの修正案を一件ずつ相談させて
```

論述の層（ronjutsu-seyo）を読んだエージェントは、案や論点が多く、利用者が混乱しているようなときに、このスキルで一件ずつ議論することを提案します。了承すると、このスキルの手順で進みます。

## 手順の要点

1. 全体の方針を一文で示す
2. 論点を、説明と推奨つきで重要な順に一覧にする
3. 一件ずつ、場所・今・案・推奨と理由・判断の材料を示して返答を待つ
4. 決まった内容を記録して次へ進む
5. 最後に、決定の一覧と残った論点を示す
