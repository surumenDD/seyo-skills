# kowake-seyo

案や論点を一度に並べると、利用者は全体を把握できず、判断が雑になるか止まる。このスキルは、全体の方針を先に示したうえで、案を一件ずつ出して決めていく手順を定める。

## 使う場面

- 利用者が名前を出して頼んだとき。
- 案や論点が多く、利用者が混乱している兆しがあるとき。この場合は、一件ずつ議論する進め方をまず提案し、了承を得てから使う。兆しの例は次のとおりである。
  - 「情報量が多い」「わからない」などの言葉
  - 同じ質問の繰り返し
  - 判断を避けた短い返事

## 手順

1. 全体の方針を一文で示す。何をどの方向に直す案なのかが分からないまま一件を見ても、利用者は判断できない。
2. 論点を一覧にする。各論点に短い説明と推奨を付け、重要な順に並べる。呼び名だけの一覧にしない。
3. 一件ずつ示して返答を待つ。示すのは次の五つである。
   - 場所（ファイル、節、段落、枚）
   - 今の文や状態
   - 案
   - 推奨と、その理由
   - 判断に要る材料（前後の文、見た目なら画像）
4. 決まった内容を記録し、次の論点に進む。返答に質問が含まれていれば、先に答え、決定を確かめてから進む。記録の置き場は、プロジェクトの決まりに従う。決まりが無ければ、会話の中で一覧として示す。
5. すべて終えたら、決定の一覧と、残った論点を示す。

## 守ること

- 一件の中に別の論点を混ぜない。混ぜると、利用者はどれに答えればよいか分からない。
- 判断に要る材料は、こちらで先にそろえる。利用者に一問ずつ読み取りを確かめさせる形にしない。
- 決まった論点を、あとの論点の議論で黙って変えない。変える必要が出たら、別の論点として示す。
