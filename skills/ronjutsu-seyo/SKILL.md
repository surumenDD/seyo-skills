# ronjutsu-seyo（論述の層）

## 使い方

1. 文書の種類を決める。呼び出したスキルか利用者が種類を指定していれば、それに従う。
2. 文体の層（buntai-seyo）も同じ種類について読む。同じ親フォルダの `buntai-seyo/SKILL.md` にある。
3. 利用者の指摘の図鑑があれば読む（次の節）。
4. 同じ会話では読み直さない。文脈が圧縮されたあとに書くときは読み直す。

文章の確認に使った結果は候補として扱い、目的と図鑑の注に照らして採否を決める。

## 利用者の指摘の図鑑

利用者の指摘の原文を、プロジェクトごとの図鑑にまとめている場合がある。図鑑の場所は、このスキルと同じ親フォルダにある `chosei-seyo/scripts/seyo_where.py` で調べる。作業フォルダで `--kind <文書の種類>` を付けて実行すると、読む図鑑と節が表示される。表示された順に、各図鑑の冒頭の読み方と、表示された節を読む。共通の図鑑は、利用者が全プロジェクト向けに選んだ指摘だけを含むので、全体を読む。

図鑑の引用は利用者の発言そのものであり、例として読む。規則として字義どおりに適用せず、注に書かれた範囲の外に適用しない。図鑑と層が食い違うときは、その利用者については図鑑を優先する。図鑑が無い場合や chosei-seyo が無い場合は、層だけで進める。

## 論述の層

対象は、論文・発表・報告・メール・AI 向けの文書などの論理的な文章である。発表のように聞かせる文章も含む。語と表記は文体の層が扱う。文書の種類の名前は、二つの層で共通である。

## 1. 目的

論理的な文章の役割は、読み手の知らない知見を既知の事柄と関係づけて示すことである。研究論文では、先行研究で未解決の問題とそこから生じる問いに対する本研究の答えを示す。道具の紹介や進捗の報告など研究以外の文書では、読み手が直面している課題が問題にあたる。価値は問題との関係で決まる。問題を定義せずに対処を述べると、読み手は何が解決されたのかを判断できない。事実は主張の根拠として示す。事実を並べただけでは、それが何を支えるかを読み手自身が組み立てなければならない。時間の限られた査読者はその作業をせず、前に戻れない聴衆にはそれができない。

事実を隠さないことと、主張として掲げることは別である。不利な事実も削除しない。ただし主張にはせず、主張が成り立つ範囲を限定する根拠として扱う。

## 2. 書く前に決めること

- 読み手と、その箇所までに読み手が得ている知識を決める。
- 読み手に示す価値を一文で言えるようにし、それを支える論証を組む。研究では次の順に論じる。
  1. 先行研究で未解決の問題
  2. そこから生じる問い
  3. 問題を克服する対処と、それが有効な理由
  4. 測定の結果
  5. 得られる価値

  根拠のない段は、文を弱めて残すのではなく、根拠を差し替えるか削除する。弱めた文を残しても、論証の欠落は補えない。
- 書き出しは、読み手と共有できる大きな問いから始める。細部から始めると、読み手はなぜそれを読むのか分からない。
- 段落ごとに、論じる中心を一文で決める。発表では一枚ごとに決める。一文で言えない段落は、位置が適切でないか、不要である。
- 文案より先に構成を決める。細部の不具合（指す先の分からない語、内容から導かれない接続、問題より先に出る設計）は、多くの場合、論理のつながりが欠けている兆候である。その場合は一文の書き直しやつなぎの句、予告の追加では解消せず、構成から見直す。要素がそろい論理がつながっているなら、組み替えずに表現と順序を直す。組み替えると、正しかった要素まで失われる。
- 手本は実物で確かめる。手本とは、同じ分野の論文、学術発表のスライド、投稿先の様式である。確かめる点は、章の順序と役割、本文での数値の扱い、章どうしの重複、脚注や注の書き方である。手本から学ぶのは型であり、言い回しや結論の方向は写さない。型が扱っていない場面にも、型の理由を適用する。

## 3. 原則

### 3.1 各文は前の文を受ける

各文は、前の文の理由・帰結・前提のいずれかとして続ける。「したがって」で結ぶ前に、結論に必要な前提が文中か直前にそろっているかを確かめる。よくある飛躍は二つある。一つは、変えていない条件を並べただけで、変えた条件を述べずに差の原因を結論する形である。もう一つは、何が示されたかを述べ、どう示されたかを省く形である。飛躍は間の文を削っても解消しない。不足した前提を結論の前に補う。段落や枚の末尾で次に扱う問いを示すときは、その内容から導く。問いを受けた段落や枚は、その答えから始め、答えから導く次の論点を後に続ける。答えを省くと、読み手は問いに答えが出たと判断できない。

### 3.2 事実には意味を添える

事実を述べたら、それが主張にとって何を意味するかを書く。つまり、問題を示すのか、対処が有効であることを示すのかを書く。論証の中の文は、このどちらかを示すか、その理解に必要な説明を述べる。いずれにも当たらない文は 3.3 の対象である。問題の名前を挙げるだけでは、何が失われるかは伝わらない。具体の値や差は、それが示す欠陥や性質を述べたうえで根拠として短く添える。意味の分からない事実のあとに逆接を置くと、何が反転したのかが分からない。同じ問題の二つの面や、指標とそれが測る現象は、一つの問題として述べる。別々に並べると、問題が二つあると読まれる。

すべての段を良い結果か悪い結果で締めくくる必要はない。先に示した問いに答える証拠の区間では、対処が有効であることを示す事実が続いてよい。ただし強調しすぎると、主張が疑われる。

### 3.3 論旨に接続しない文を置かない

次の文は、なぜそこにあるのかが読み手に分からない。

- まとめの位置で、文脈から自明な内容を言い直す文
- あとで使わない具体値、設定、用語の定義を一つだけ示す文
- 文脈を知らない読み手には意味を読み取れない修飾
- 別の節の内容を差し込み、段落の主題から外れる文
- 何のためにあるかを説明できない注、脚注、断り書き

直し方は二つある。削除するか、文脈を補って論旨に接続させるかである。判断の基準は語ではなく位置である。同じ趣旨の文でも、別の位置では必要な場合がある。

### 3.4 否定、断り、例外の重ね

未測定の項目や未実施の作業、書き方の方針を断る文は、主張を変えないまま弁明として読まれる。その結果、主張が不明瞭になる。未実施の作業を理由の説明だけで済ませると、気づいていながらなぜ行わないのかと読み手は問う。実施する手段があれば実施する。なければ、何があれば実施できるかと、その限界のもとで何が言えるかを書く。読み手の判断を変える限界は、主張が成り立つ範囲として主張の文の中に書く。例外は名指しして一度だけ述べる。全体のうちいくつで成り立つかを述べてあれば、別の文で例外を強調しない。重ねて述べると、結果の価値を二度下げる。それ以外の断りは本文から削除する。理由と数値を添えて別の記録に残し、依頼者に報告する。報告では、依頼者の判断に必要な限界と未実施を隠さない。

### 3.5 主語

主語には、文書の主張につながる対象を選ぶ。論文では提案手法か本研究である。提案と貢献を述べる文では、本研究（発表では「私たち」）を主語にして誰の提案かを示す。手法を主語にした文だけでは、帰属が分からない。先行研究は、解決すべき問題のある研究として扱う。結論を先行研究の名前で始めない。要約の位置（要旨・貢献・結論）では、対照条件や図表を主語にした判定を書かない。図表を解説する箇所では、観測した事実をそのまま書いてよい。

### 3.6 数値と判定

数値は図表で示す。本文には、手法単位の傾向とそこから導かれる結論を書く。値の大小がそれぞれ何を意味し、そこから何が分かるかという抽象度で書く。試行ごとの勝ち数を書くと具体的すぎて、論旨が見えにくくなる。ただし、意味の理解に必要なおおよその大きさは書いてよい。図の推移を一つずつ文章で説明すると、図と重複する。「上回る」「同水準」と書くときは、何を基準にした判定かを明示する。基準は分野の慣例に合わせる。結果を文字の判定でまとめた表は、書き手の裁量で内容が決まるので、測定にはならない。表には、測定値かそこから計算した量を載せる。

### 3.7 主張の強さ

主張は、根拠が支える範囲で言い切る。主語の範囲を、扱った対象より広げない。一部だけを扱ったなら、その範囲を先に述べる。後続研究が結果をどう使うかを、確定した事実のように書かない。主張を支える結果どうしに優劣をつけない。読み手の注意が、主張と関係のない問いに向かう。論文から発表や要約を作るときは、範囲と強さを論文の言い回しではなく根拠に合わせる。言い回しが根拠より弱ければ、根拠の範囲で言い切ってよい。一方、論文が可能性として述べた内容を、根拠を足さずに原因として言い切らない。出典を示す句は、主張を弱める句ではなく帰属を示す句なので残す。

### 3.8 不利な結果の置き方

主張の範囲を変える不利な結果は、本文で一度、事実として述べる。範囲を変えない細部は付録に回し、本文から参照する。読み手の判断は、要旨・貢献・最初に見る図で決まる。最初に見せる図として、主要な比較が一目で分かる図を選ぶ。

### 3.9 長さ、重複、追加、削除

一つの主張は、本来の節で一度だけ書く。繰り返してよいかは、前に述べた位置からの距離で決まる。隣の文や前の段落、前の枚と内容が重なり、わずかな情報だけを加える文は重複である。章の単位で見ると、冗長と判定される。離れた位置で前の内容を前提にする文には、短い言い直しを添える。前に戻れない発表では、その距離が論文より短い。

削除するときは、論証のつながりと主張の範囲を決める語を残す。削除には一つずつ理由を持つ。分量を詰めるときも、内容と決めた条件は保つ。意味や含みを担う例や文を、語数のために外さない。外すのは、画面や図が示す細部、前と重なる文、主張に寄与しない説明である。追加は、主張を強めるか弱めるかで判断する。長さは、内容を過不足なく述べた結果である。紙面や語数の目標に合わせて増やすと、重複と論旨に接続しない文が増える。上限を超える内容は次の節や枚へ移す。間に合わない検証は、欄を空けて示す。

### 3.10 改稿後の整合

一部を改稿したら、それを要約する箇所（要旨・序論・貢献・考察・結論）を確認する。前の版から引き継いだ文には、根拠がなくなったまま判定の形だけが残っている場合がある。評価の基準を変えたら、付録を含めて古い基準の図表と文を削除する。残すと、読み手はどの基準で判断すべきか分からなくなる。前の改稿で直した点（切った長い文、決めた言い切り）が戻っていないかも確かめる。

## 4. 文書の種類による違い

種類の項は第 3 節と併せて適用する。項のない種類には、読み手が近い種類の項を適用する。

### 論文

| 章 | 役割 |
|---|---|
| 要旨 | 問題が何で、対処がなぜ有効で、何が得られたかが文意から分かるように書く。要素を順に並べるだけでは足りない |
| 序論 | 分野の問いから始める。先行研究が解決した点と未解決の問題を因果でつなぎ、問題を読み手と共有してから提案に進む。理解を助ける具体的な状況は示してよい。提案は数式ではなく用語で説明し、後の章の結果や式を持ち込まない |
| 貢献 | 価値の面ごとに一項目を立てる。面とは、問題と解決と新しさ、既存手法に対する性能、後続研究への寄与である。章や作業の単位で数えず、数値も並べない。各項目の方向を全体の主張とそろえる |
| 関連研究 | 着想が同じ研究を、本研究の問題との関連が深まる順に述べる。違いは章の最後に、手法の細部より高い抽象度で述べる。問題提起の起点を序論とそろえる |
| 手法 | 提案手法を中心に書く。冒頭では、既存手法との違い、それにより得られる利点、節の構成を述べる。変更の少なさや設定の引き継ぎを主張にしない。先行研究を診断してから提案する構成では、提案後に得た結果を診断に含めない |
| 実験 | 手法の章で立てた問いと設計の根拠を回収する。章をまたぐつながりは節番号に任せず、文で述べる。小括は、その節の本文から導く |
| 考察 | 結果の解釈と、主張の中での位置づけを書く。未実施の作業の扱いは 3.4 に従う |
| 結論 | 本研究を主語にして、示した事実・提案・得られた知見・価値の順につなぐ。「示した」で終えない。新しい事実や観点、引用を持ち込まない。展望は、結果から因果で導け、序論の目的と方向が一致する内容に限る。同種の手法への適用を展望に挙げても、後続の研究に何をもたらすかは示せない |

### 発表（スライドと台本）

聴衆は前に戻れない。一枚を見る時間も話し手が決める。論文なら読み返して補える欠落が、発表ではそのまま理解の欠落になる。

| 要素 | 基準 |
|---|---|
| 構成 | 冒頭で、何を示す発表かを短く述べる。先行研究の問題を定義し、研究の問いを明示してから対処に進む。後半の結果は、その問いへの答えとして並べる。問いは、結論で答えを言い切れる形に立てる。問いが明示されていれば、聴衆は前の枚を思い出すことに注意を割かず、貢献について考えられる |
| 枚のつなぎ | 前の枚で示した問いを、次の枚の見出しか冒頭で受ける。先に示した問いに複数の枚で答える区間では、各枚がその問いの一つに答えて完結すればよい。この区間では、枚の間のつなぎは要らない |
| 見出しと台本 | 一枚ごとに画面と台本を対応させる。台本の最初の文は、見出しと同じ主語・同じ内容にする。両者が食い違うと、見出しを読まない聴衆は戸惑う。食い違いは、どちらかが誤っている兆候でもある。台本で触れない図表は載せない。詰めすぎた枚は分ける。短い枚が多くてよい |
| 図 | その枚で何を見せるかを先に決めてから図を選ぶ。例に使う対象で起きない現象を、その対象の図で見せない。補足の要素は目立たせない |
| 結論 | 問いへの答えは、問いの形にせず平叙文で言い切り、続けて貢献を述べる。問いを示した枚から離れているので、答えの文に問いの中身を含める。本編にない事実や考察は、付録と質疑に回す |
| 論文との関係 | 発表は論文とは別の文書である。論文の式、設定の細部、言い回しを台本に持ち込まない。用語は文体の層に、主張の強さは 3.7 に従う |

### 報告、説明の返答

結果を返す文は、事実を並べるのではなく、主張と論証にどう寄与する材料かでまとめる。問いには最初に答える。前提や条件を狭くも広くも読み替えず、問われていない問題点や案、相手が既に知っている内容を足さない。判断が必要な点は先頭に置き、推奨と根拠を添える。説明を求められたら、結論を言い直すのではなく、事実から結論に至る段を書く。各段には、出所（測定・文献・書き手の解釈）と論理が途切れる箇所を示す。

記録と推測を分ける。問いの前提が記録にない場合は、そう答える。根拠は、該当箇所に何が書いてあるからその結論になるのかで示す。削除や変更、前に推した案からの変更には理由を添える。確認した範囲を超えて強く書かない。検査が通ることと目的を果たすことは別である。書き手自身が問題ないと考えるかを、根拠とともに述べる。判断を求めるときは、判断できる中身を示す。中身とは、今の文と案、前後の文、見た目なら画像である。判定や見出しだけで承認を求めない。

### 査読への回答

指摘に答える文を本文に足すと、弁明として読まれる。まず、指摘が問題にしているのは主張の範囲の広さか、根拠の欠落かを特定する。次に、範囲を根拠に合わせて言い直すか根拠を差し替え、論証の中に組み込む。修正の箇所と内容は、回答の文に書く。弁明にしかならない指摘は、採らない理由を添えて依頼者に示す。

### 外部の相手へのメール

内容は、相手が確認・判断・行動に使う範囲に限る。こちらの作業の経緯は、相手の判断に使えないので書かない。ただし、原因がこちらにないことを示す事実のように、判断に必要な根拠は入れる。依頼の理由と内容をつなげて書き、根拠は結論の前に置く。こちらが既に知っている事柄を相手に尋ねない。

### AI 向けの文書（指示書、スキルの本体）

目的と、作業の構造が変わっても使える手順を書く。数値で測れる条件は厳密に決める。判断を要する部分は目的と理由で伝え、両者を一つの指示に混ぜない。その場限りの役割、過去の一例でたまたま通用した手順、価値を説明できない規定を固定すると、優れた受け手ほど制約される。受け手は数値の目標や規則を字義どおりに守る。軽い付け足しとして書いた確認は、その程度の深さで終わる。長さは目的と上限で指定する。

確認の手順を挟むかは、誤ったときの手戻りの大きさで決める。調査では、存在しないと分かっている証拠を求めさせず、慣例を含む一般論を集めさせる。集めた推奨が、いつの時点の、どのモデルに向けたものかを確かめる。独立した見方が必要なときは、自分の結論や判断を偏らせる資料を渡さない。成果物は形式の基準だけで合格とせず、目的を果たしているかを一次資料で確かめる。

### 研究の提案

テーマと仮説、新しい手法とその具体化、検証の内容、新規性の所在を示し、分野の根本的な目的と結びつける。既存の要素の組み合わせであれば、新規性の所在か、検証の後の構想を示す。出発点が依頼の条件（新しい研究か、既存研究の延長か）を満たすかを確かめる。

### 一般の読み手への説明

初見の読み手を前提にする。特定の文書の固有名、引用、数値は入れない。平易にするときも、元の文書の主張と用語を変えない。

## 5. 読み直しの問い

- 各文は前の文を受けているか。問題か対処のどちらかを示し、問いに直接答えているか。
- 近い位置での重複、離れた位置での言い直しの欠落、主張を変えない断りはないか。
- 主張の強さと主語の範囲は、根拠に見合っているか。改稿の後も、要約する箇所と以前の修正が本文と整合しているか。

## 6. 方針の持ち方

- 目的を規則より優先する。この層の項目・過去の決定・助言は、いずれも目的と読み手の必要に照らして適用する。規則に合っていても論旨に接続しない文は直し、規則から外れていても必要な文は残す。
- 指摘は、その箇所で何が問題だったかと、その理由として受け取る。同じ理由が当てはまる箇所には広げるが、語の禁止や約束の形の規則にはしない。規則にすると適用しすぎて、必要な語まで削ってしまう。依頼者の語を字義どおりの基準にせず、何を問題にしているかを読み取る。
- 指摘された箇所は、同じ型の一例であることが多い。同じ型の箇所を探し、一つずつ判断する。その際、修正がほかの観点（配置、ほかの枚）を損なっていないかも確かめる。広げるのは理由が当てはまる箇所までとし、すでに決まった箇所を変える案は出さない。
- 元の文書、ほかの AI の出力、前の版、過去の資料は、根拠を確かめてから使う。どれにも誤りは混じる。特に前の版の形や判定は、根拠が変わっても残りやすい。誤りを見つけたら、根拠を示して訂正する。
- 依頼者と合意した内容は、依頼者が変えるまで保つ。依頼者の意見に誤りがあると考えるときは、内容を変えずに、根拠を添えて指摘する。
- 依頼者の発言も自分の発言も、会話の途中で一貫しなくなることがある。依頼者自身が矛盾に気づいていない場合もある。自分の前の発言は、その時点の理解に基づく方針にすぎない。矛盾に気づいたら、前の発言に合わせる必要はない。目的に照らして考え直してよい。ただし依頼者と合意した内容の扱いは、前の項に従う。
