# ronjutsu-seyo（論述の層）

論理的な文章で何をどの順に主張するかの基準を定めたスキルです。対象は論文、発表、報告、メール、AI 向けの文書などです。語と表記の基準は、対になる buntai-seyo（文体の層）が定めます。

このファイルは人が読むための説明です。エージェントが読むのは `SKILL.md` です。

## 何を定めているか

| 節 | 内容 |
|---|---|
| 1. 目的 | 読み手の知らない知見を、既知の事柄と関係づけて示す |
| 2. 書く前に決めること | 読み手、示す価値、論証の順序、構成、手本の確かめ方 |
| 3. 原則 | 文のつながり、事実の意味、論旨に接続しない文、断りの重ね、主語、数値と判定、主張の強さ、不利な結果、重複、改稿後の整合 |
| 4. 文書の種類による違い | 論文の章ごとの役割と、発表、報告、査読への回答、メール、AI 向けの文書などの基準 |
| 5. 読み直しの問い | 書いたあとに確かめる三つの問い |
| 6. 方針の持ち方 | 規則より目的を優先する。指摘、合意、会話の途中の発言の扱い |

## 論証の進め方

論証は、問題を示す事実と、対処が有効であることを示す事実の反転で進みます。前者を−、後者を＋と呼びます。エージェントは事実を述べたら、その事実が問題を示すのか、対処が有効であることを示すのかを本文に書きます。反転のない事実の並びは、聞き手には羅列に聞こえるからです。slide-seyo の構成案にある「＋−」の列はこの区別を示します。

## 利用者との進め方

- 利用者と合意した内容は、利用者が変えるまで保ちます。利用者の意見に誤りがあると考えるときは、内容を変えずに根拠を添えて指摘します。
- 利用者の発言もエージェント自身の発言も、会話の途中で一貫しなくなることがあります。エージェントは矛盾に気づいたら、前の発言に合わせず、目的に照らして考え直します。合意した内容は前の項のとおり保ちます。
- 案や論点が多いときは、全体の方針を先に一文で示し、一件ずつ推奨を添えて返答を待ちます。利用者が混乱しているようなら、kowake-seyo で一件ずつ議論することを提案します。kowake-seyo が入っていなければ、エージェントが同じ進め方で進めます。

## 使い方

名前を出して頼みます。

```
ronjutsu-seyo で、この節を書き直して
```

エージェントは文書の種類を決め、論述の層と文体の層を同じ種類について読みます。作業中のプロジェクトに利用者の指摘の図鑑があれば、書く文書の種類の節と「進め方」の節も読みます。そのあとで書きます。slide-seyo と delegate-seyo は、文章を書く場面でこの層を読むようエージェントに指示します。

二つの層と図鑑の関係はリポジトリの [README](../../README.md#仕組み) にあります。

## 測定で分かっていること

作者 1 人の記録で測りました。記録は、論文の推敲と発表の準備で、作者が AI の文章に出した指摘です。別のモデルに、層と、指摘を言い換えてまとめた文書を渡しました。この文書は chosei-seyo の以前の形です。利用者の指摘を別の担当が言い換え、1 つの短い文書にまとめていました。

試験では、利用者が読んでいた文章を別のモデルに見せます。指摘の再現では、利用者が指摘すると考える問題を、件数の上限つきで挙げさせます。書き直しでは、同じ文章を書き直させ、利用者が指摘した問題が解消したかを判定します。手順は [harness/PROCEDURE.md](../../harness/PROCEDURE.md) にあります。

| 問い | 結果 |
|---|---|
| 取り込んだ指摘を、同じ材料で再現できるか | できました。再現率は、論文の推敲の記録で 15.6% から 52〜53% に、発表の準備の記録で 25.2% から 44.3% に上がりました |
| 取り込んだあとの新しい材料に利用者が出す指摘を、予測できるか | できませんでした。差は +3.0 ポイントで、95% の区間は 0 を含みます |
| 新しい材料の草稿を書き直すと、指摘された問題は減るか | 減りました。解消率は 12.8% から 26.6% に上がりました（差の 95% の区間は +0.3〜+30.2 ポイント）。ただし 27 件中 18 件は解消しませんでした |
| 言い換えてまとめた文書は原文を読ませる方法を上回るか | 上回った測定はありません。取り込み済みの材料では 52〜53% 対 59.1%、新しい材料では 31.6% 対 36.0% でした。後者の差の 95% の区間は 0 を含みます |
| 副作用 | 文章の確認に使うと、利用者が直さなくてよいと決めた箇所を問題として挙げる件が増えました（18 か所中 3 → 7）。書き直しでその箇所を壊した件は 0 でした |

言い換えてまとめた文書が原文を上回った測定は無かったので、図鑑は利用者の指摘を言い換えずに原文のまま引く形にしています。

ほかの利用者の記録、白紙から文章を書く場合、書き直したあとの層、原文を引く図鑑の形は、まだ測っていません。

## 層の改訂

層はすべての利用者が読む既定です。chosei-seyo の取り込みで変わるのは、取り込んだ利用者の図鑑だけです。層の改訂は保守者が行います。手順は chosei-seyo の [references/maintainer.md](../chosei-seyo/references/maintainer.md) にあります。
