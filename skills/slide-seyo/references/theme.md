# デザインの設定値

色、フォント、余白の既定値と、その差し替え方をまとめた。会場や所属のテンプレートやユーザーのデザイン文書があればそちらの値を使うが、差し替えても可読性の検査は同じように実行する。

## 1. 既定のテーマ

スライドのサイズは 16:9、13.33 × 7.5 in とする。HTML では 1920 × 1080 px とし、1 in = 144 px、1 pt = 2 px で換算する。会場が 4:3 を指定している場合は、それに合わせる。

配置

| 項目 | 値 | HTML での値 |
|---|---|---|
| 左右の余白 | 0.6 in | 86 px |
| 見出しの上端 | 0.42 in | 60 px |
| 本文の開始位置 | 1.6〜1.75 in | 230〜250 px |
| 最下行（出典、ページ番号）の上端 | 6.95 in | 1001 px |

本文の開始位置は全スライドで同じにし、見出しのすぐ下に文字の行が来るスライドが多い場合は広い方の値を選ぶ。狭いと、見出しとの間が詰まって見えるからである。

最下行には出典を左に、ページ番号を右に置き、位置を全スライドで同じにする。表紙にはページ番号を置かない。

文字

| 役割 | サイズ | 太さ |
|---|---|---|
| 表紙のタイトル | 36〜40 pt | 太字 |
| 見出し | 28 pt（2 行に収まらなければ 26 pt まで） | 太字 |
| 本文 | 20〜24 pt | 標準 |
| 説明、図の中の文字、コード | 18 pt 以上 | 標準 |
| 出典、ページ番号 | 14 pt | 標準 |

明朝体やセリフ体は細い線が投影で消えやすいので、フォントはサンセリフを 1 種類にする。日本語はゴシック体（Noto Sans JP など）、英語は Calibri や Arial のような癖のないものを使い、コードとコマンドだけ等幅フォントにする。

色

| 役割 | 値 | 背景 #FAFAFA とのコントラスト比 |
|---|---|---|
| 背景 | #FAFAFA | — |
| 本文、見出し | #1E1E1E | 16:1 |
| 説明（本文より 1 段階薄い） | #404040 | 10:1 |
| 出典、ページ番号 | #5A5A5A | 6.6:1 |
| 枠、矢印、補助線 | #555555 | — |

識別の色

対象（比較する手法、ツール、条件）ごとに 1 色を決め、全スライドで同じ対象を同じ色で示す。色は、色覚の多様性に配慮した組み合わせ（Okabe–Ito の配色）から選ぶ。

| 色 | 線、棒、枠 | 大きい太字の文字 |
|---|---|---|
| 橙 | #D55E00 | #C04F00 |
| 青 | #0072B2 | #0072B2 |
| 緑 | #009E73 | 文字には使わない（コントラスト比が足りない） |

- 識別の色は 3〜5 色までにし、それより多い場合は色で区別するのをやめてラベルを直接付ける。
- 識別の色を文字に使うのは、大きい太字（18 pt 以上の太字か、24 pt 以上）だけにする。小さい文字は本文の色にして、色見本（小さな四角）か位置で対象を示す。
- 色だけで区別せず、線の種類、ラベル、形を併用する。
- 強調の色（ここを見てほしい、という色）は識別の色とは役割が違い、1 枚に 1 か所にする。

## 2. HTML での定義

値は 1 か所（共通のスタイルの冒頭）にまとめ、由来をコメントで残す。そうしておけば、あとでテーマを差し替えるときにそこだけを変更すれば済む。

```css
/* 13.33 x 7.5 in のスライドを 1920 x 1080 px に換算（1 in = 144 px、1 pt = 2 px） */
:root {
  --bg: #FAFAFA;
  --ink: #1E1E1E;
  --ink-2: #404040;
  --note: #5A5A5A;
  --rule: #555555;
  --id-a: #0072B2;          /* 対象 A。線、枠 */
  --id-b: #D55E00;          /* 対象 B。線、枠 */
  --id-b-text: #C04F00;     /* 対象 B の名前（大きい太字だけ） */
  --margin: 86px;
  --headline: 56px;         /* 28 pt */
  --body: 44px;             /* 22 pt */
  --small: 36px;            /* 18 pt */
  --note-size: 28px;        /* 14 pt */
}
```

## 3. 差し替え方

| 場面 | 対応 |
|---|---|
| 会場や所属のテンプレートがある | テンプレートの色、フォント、余白、ロゴの位置を使う。構成の原則（見出しに主張を書く、証拠の示し方を選ぶ）は変えない。テンプレートの見出しの枠が 1 行分しかなければ、主張を短く言い切る |
| ユーザーやプロジェクトにデザインの文書がある | その値を使う。値がない項目だけ、既定で補う |
| 手元の画面で見せる（投影しない） | コントラスト比の下限を、画面用の基準まで下げてよい（`legibility.md` の 2）。下げたことを構成案に書く |
| 広い会場 | 文字サイズの下限を上げる |
| 題材が既定の色に合わない（色そのものに意味がある題材など） | 識別の色を選び直す。コントラスト比と色覚の確認は同じように行う |

差し替えたテーマが可読性の基準を満たさない場合（テンプレートの薄い文字色、小さい脚注など）は、黙って従わずに、どの値が基準に届かないかをユーザーに伝え、代わりの値を 1 つ提案する。テンプレートを守る必要があるかどうかは、ユーザーが決める。

## 4. テーマに含めないもの

次の項目は、デザインの好みではなく可読性の基準か構成の原則なので、テーマを差し替えても変えない。

- 文字サイズの下限、コントラスト比の下限、はみ出しと重なりがないこと（可読性の基準）
- 見出しに主張を一文で書くこと、1 枚に主張を 1 つ置くこと、出典の位置と書式を統一すること（構成の原則）
- 装飾を置かないこと（`patterns.md`）。ただし、テンプレートに含まれるロゴや帯は、テンプレートの一部として残す
