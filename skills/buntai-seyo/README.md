# buntai-seyo（文体の層）

語の選び方、文の構成、強調、表記の方針を、文書の種類ごとにまとめたスキルです。何をどの順で主張するかは、対になる ronjutsu-seyo（論述の層）が扱います。

このファイルは人が読むための説明です。エージェントが読むのは `SKILL.md` です。

## 基準の考え方

語は、その分野で定着しているかどうかで選びます。和語か漢語かでは選びません。文体の基準は文書の種類で切り替えます。論文と技術文書は密度のある書き言葉、発表の台本は聞いて理解できる文、スライドの文言は短い句です。1 つの文体を全種類に当てると、技術文書が平易すぎる文になるか、台本が読み言葉になります。

日本語の研究論文の一般の規範（japanese-research-writing）を土台にし、その要点と、規範に書かれていない点を書いています。

## 使い方

名前を出して頼みます（「buntai-seyo で、この README を直して」）。エージェントは、文章の種類を決め、文体の層を読み、論理で読ませる文章であれば論述の層も読み、最後に、そのプロジェクトの図鑑（利用者の指摘の原文）を読んでから書きます。

構成、測定で分かっていること、層の作り方は、ronjutsu-seyo の `README.md` にあります。
